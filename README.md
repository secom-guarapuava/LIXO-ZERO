# Semana Lixo Zero · Guarapuava

Manual digital de separação de resíduos das secretarias municipais de Guarapuava (Semana Lixo Zero Paraná 2026). Segue a linguagem visual do APP Guarapuava Mais Verde e conversa com o site da coleta seletiva.

## Publicar no GitHub Pages

1. Crie um repositório na organização `secom-guarapuava` (por exemplo, `SEMANA-LIXO-ZERO`).
2. Envie todo o conteúdo desta pasta: `index.html`, `README.md` e a pasta `assets/`.
3. Em Settings → Pages, escolha a branch `main` e a pasta raiz (`/`).

## Adicionar um material

Na seção `#materiais`, copie um bloco `<article class="mat">…</article>`, troque a imagem de capa, o título e o link do arquivo. Coloque o arquivo novo em `assets/img/` ou `assets/docs/`.

## Estrutura

- `assets/img/` — Guarazinho (4 poses), logos, placas das lixeiras, stories e capa da cartilha
- `assets/docs/` — Cartilha da Compostagem (Composta Paraná)
- `assets/fonts/` — cópia local de Bricolage Grotesque e Space Grotesk, usada se o Google Fonts não carregar
